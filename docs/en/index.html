Install

Three steps, ready to use

Download

Download Hey-1.1.0.dmg from the Releases page, then double-click to open

Drag to Applications

Drag the Hey icon onto the Applications folder in the same window

first launch

The app is not notarized by Apple; see how to allow it below, once is enough

Install with one command (no warning)

Open Terminal and run this. It downloads the latest version with curl into Applications and opens the app. macOS does not ask because files downloaded with curl carry no quarantine flag

curl -fsSL https://raw.githubusercontent.com/giganto-th/hey/main/scripts/install.sh | bash

If you download the .dmg yourself and macOS says it cannot be opened

Hey! is signed ad-hoc, not through an Apple developer account, so macOS asks before the first launch. Pick either way

  1. Through Settings: Open the app once so the warning appears, then go to System Settings › Privacy & Security, scroll down and press "Open Anyway" for Hey
  2. With Terminal: Remove the quarantine flag, then open as usual 
    xattr -dr com.apple.quarantine /Applications/Hey.app
  3. Build it yourself: An app you build on your own Mac is not quarantined; see the README (bash scripts/make-app.sh)

If a permission doesn't stick after an update, remove the Hey entry in System Settings and allow it again
