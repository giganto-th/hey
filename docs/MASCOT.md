# Hei Hei — ตัวละครหลักของ Hey!

ทิศทางใหม่ตามคำขอผู้ใช้: อิง Hei Hei จาก Moana ฉบับแอนิเมชัน ทั้งรูปลักษณ์และบุคลิก เอกสารนี้แทนแนวทาง Tok เดิม

- คอยาวสีเหลืองทอง ลำตัวเล็กสีน้ำตาล ขาเรียวเหลืองส้ม
- ตาขาวโปน รูม่านตาเล็ก มองแยกทิศกัน หงอนและเหนียงสีแดง
- หางโค้งเป็นพวงสีเขียวอมฟ้า ปีกเล็ก เคลื่อนไหวไม่สมมาตรเล็กน้อย
- ดูซื่อ งง ช่างสงสัย; ความตลกเกิดจากท่าทาง ไม่ทำให้คำสั่งหรือข้อมูลของผู้ใช้ผิดพลาด

## ตัววาดที่ใช้งานจริง
`Sources/Hey/HeiHeiRig.swift` วาดชิ้นส่วนด้วย SpriteKit และ Core Graphics หัว คอ ปีก หาง ตา และขาขยับแยกกัน คีย์บอร์ดกับอาหารเป็น prop แยก ตัววาดเดียวกันใช้ทั้งบน desktop และตัวอย่างใน Hub

พฤติกรรมถูกเลือกโดย `Sources/HeyDomain/CompanionMotion.swift` โดยแยกการอุ้ม/ตก การรับคำสั่ง การพิมพ์ โฟกัส และเพลง พร้อมข้อจำกัดเมื่อร้อน/แบตวิกฤต

เซฟ v1 ที่ใช้ Tok เปลี่ยนกลับเป็น Hei Hei ใน schema v2 โดยเก็บความคืบหน้าและชื่อที่ผู้ใช้ตั้งเองไว้ ภาพ raster ของ Hei Hei เดิมยังอยู่สำหรับไข่และทางเลือกสำรอง
