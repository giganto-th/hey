# Hey! sprite generation

Generated using the built-in ImageGen tool with `transparent_background: true`. All seven final files are 1024×1024 RGBA PNGs in `Resources/Sprites/_gen/`. ImageGen returned 1254×1254 originals, which were resampled to the requested dimensions using macOS `sips` with alpha preserved. PNG format, dimensions, alpha channel, fully transparent corners, and substantial fully transparent background area were checked with Pillow.

The idle hatchling was used as the exact character reference for the happy and sleeping poses, and as a style reference for the egg and foods.
