โฟกัสแบบ Pomodoro

25 นาทีโฟกัส 5 นาทีพัก พร้อมสถิติและรางวัลเป็นเหรียญกับ XP ให้เลี้ยงสัตว์เลี้ยง

ประวัติคลิปบอร์ด

ย้อนดูและคัดลอกซ้ำได้ ปักหมุดอันสำคัญ ข้ามรหัสผ่านจากโปรแกรมจัดการรหัสโดยอัตโนมัติ

อ่านข้อความจากหน้าจอ

ลากเลือกพื้นที่ แล้วอ่านข้อความไทยและอังกฤษไปไว้ในคลิปบอร์ดทันที

เตือนนัดจากปฏิทิน

แจ้งก่อนนัดหมาย 10 นาที อ่านปฏิทินอย่างเดียว ขอสิทธิ์เมื่อคุณเปิดใช้เท่านั้น

เครดิต AI หลายบัญชี

ดูโควตา Claude, Codex (ChatGPT) และ Antigravity ทุกบัญชีในที่เดียว พร้อมแถบเปอร์เซ็นต์ เวลารีเซ็ต และสัตว์เลี้ยงเตือนเมื่อใกล้หมด

ดาวน์โหลด

โหลดไฟล์ Hey-1.2.1.dmg จากหน้า Releases แล้วดับเบิลคลิกเพื่อเปิด

ลากไปที่ Applications

ลากไอคอน Hey ไปวางบนโฟลเดอร์ Applications ในหน้าต่างเดียวกัน

เปิดครั้งแรก

แอปไม่ได้ผ่านการรับรองจาก Apple ดูวิธีอนุญาตด้านล่าง ครั้งเดียวก็พอ

ติดตั้งด้วยคำสั่งเดียว (ไม่ขึ้นคำเตือน)

เปิด Terminal แล้วรัน คำสั่งนี้โหลดเวอร์ชันล่าสุดด้วย curl ลงใน Applications และเปิดแอปให้เลย macOS จะไม่ถามเพราะไฟล์ที่โหลดด้วย curl ไม่ถูกติดธงกักกัน

curl -fsSL https://raw.githubusercontent.com/giganto-th/hey/main/scripts/install.sh | bash

โหลดไฟล์ .dmg มาเอง

ตั้งแต่เวอร์ชัน 1.2.1 Hey! เซ็นด้วย Developer ID และผ่าน Apple notarization แล้ว ดับเบิลคลิกเปิดได้เลย ถ้าเคยโหลดเวอร์ชันเก่า (1.1.0 ลงไป) แล้วขึ้นคำเตือน ให้โหลดเวอร์ชันล่าสุดใหม่

ถ้าสิทธิ์ (เช่น การเข้าถึงคีย์บอร์ด) ไม่ติดหลังอัปเดตเวอร์ชัน ให้ลบรายการ Hey ในการตั้งค่าระบบแล้วอนุญาตใหม่
