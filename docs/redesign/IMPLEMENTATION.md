- ท่าว่างสุ่มด้วย `IdleVariety`: มองซ้าย/ขวา แต่งขน ยืดตัว สะบัดตัว จิกพื้น (เกิดเฉพาะตอน idle และไม่ลดการเคลื่อนไหว); ท่านอนยุบตัวซุกหัวเข้าไหล่และซ่อนขา
- สัดส่วนต่อวัย (`Look`): ลูกเจี๊ยบหัวโต คอสั้น หางและหงอนเล็ก → ไก่โตเต็มวัยสัดส่วนเต็ม
- จิกคีย์บอร์ดจิ๋วเมื่อมี key events โดยรับเฉพาะ counter/เวลา/ความเร็ว ไม่รับตัวอักษร
- พิมพ์ช้าหรือเร็วเปลี่ยนความถี่จิก; หลังไม่มี key ใหม่ 2.5 s กลับไปกิจกรรมปัจจุบัน

## Dev hooks เพิ่มเติม

ทุกตัวต้องมี `HEY_DEV=1` และควรใช้ `HEY_DATA_DIR` แยกเสมอ

- `HEY_DEV_ADULT=1`: เพิ่ม warmth/XP ให้ตัวละครทดสอบโตเต็มวัย
- `HEY_DEV_HUB=today|settings|…`: เปิด Hub ไปหน้าที่กำหนด
- `HEY_DEV_RIG_SNAPSHOTS=<dir>`: บันทึกภาพจากตัววาดจริง 5 สถานการณ์
- `HEY_DEV_LOCAL_TRACK=<audio-path>`: เล่นไฟล์ทดสอบผ่าน AVPlayer แบบ volume 0 เพื่อเช็ก callback จริง
- `HEY_DEV_LOG=1`: พิมพ์ activity ที่เปลี่ยน พร้อมสถานะ keyboard prop/amplitude ไม่บันทึกข้อความที่พิมพ์
- `HEY_DEV_RIG_FILM=<dir>`: เดิน rig จริงที่ 60 fps ทุกท่าและทุกวัย แล้วบันทึกเฟรม PNG เพื่อทำ contact sheet ตรวจการขยับ (แอปยังเปิดค้างหลังเขียนไฟล์ ให้ปิดเอง)

## เมนูวงกลมแบบกำหนดเอง

- `RadialMenuSettings` (HeyDomain): เลือก 4–6 คำสั่งจาก 11 รายการ (`RadialAction`) เรียงลำดับได้ Hub ถอดไม่ได้ ที่เหลือรวมในปุ่ม "เพิ่มเติม"; ข้อมูลเสียซ่อมตัวเองตอนโหลด
- แก้ที่ Hub → การตั้งค่า → "เมนูรอบสัตว์เลี้ยง"; "ให้อาหาร" เป็นปุ่มปกติของวง
- สี Hei Hei ปรับตามภาพอ้างอิงใหม่ (หงอนแดงชมพู ตาลาเวนเดอร์ขอบม่วง ตัวส้มเหลือง)

## แนวทางภาพนิ่ง + motion effect (รอบล่าสุด)

- ตัวละครหลักเปลี่ยนเป็นภาพที่ Codex วาด: แผ่น 12 ท่า × 4 วัย (`Resources/Pets/heihei/<stage>/<pose>.png`) + ไข่ (`egg.png`) ตัดพื้นเขียว chroma ออกและจัดเท้าให้อยู่แนวเดียวกัน; rig วาดด้วยโค้ดยังอยู่เป็น fallback เมื่อไม่มีภาพ
- `SpritePet` สลับภาพตามท่าและใส่ motion: กระโดดด้วยฟิสิกส์ แรงบีบ/ยืด เอียงตัวด้วยสปริง แกว่งตอนถูกอุ้ม + particle ที่วาดเอง (ดาว หัวใจ โน้ต เศษอาหาร ฝุ่น เส้นลม หยดเหงื่อ เครื่องหมายตกใจ ตัว Z) ไม่มี emoji
- ท่าใหม่ใน domain: `startled`, `dizzy`, `flap`, `fly` (PetPose) / `startled`, `dizzy`, `flapping`, `flying` (CompanionActivity)
  - คลิก = ดีใจ, ดับเบิลคลิก = ตัวโตกระพือปีก (วัยอื่นดีใจ), เขี่ยตอนหลับ = ตกใจ
  - ลากเขย่าซ้าย-ขวา หรือปล่อยตกจากที่สูง = มึนหลังลงพื้น
  - ตัวโตฝึกกระพือปีกเอง และบินสั้น ๆ เป็นวงโค้งในหน้าจอ (ปิดได้ด้วย "เดินสำรวจ" ในตั้งค่า)
- ตัวตรวจภาพ: `HEY_DEV=1 HEY_DEV_PET_FILM=<dir>` เขียนเฟรมของทุกท่า (แอปเปิดค้างหลังเขียนไฟล์ ให้ปิดเอง)
- เครื่องมือตัดแผ่น: ดู `docs/SPRITE_PIPELINE.md`
